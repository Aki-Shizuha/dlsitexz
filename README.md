# DLsite 游戏信息浏览器

自动抓取 DLsite 游戏信息并提供本地 Web 浏览界面，支持收藏分类、屏蔽筛选。

**单文件 Go 二进制，开箱即用，无需外部依赖。**

## 功能

- 批量爬取 DLsite 作品信息（标题、社团、简介、图片、价格、评分、标签等）
- 单个作品 ID 快速获取
- 现代化深色 Web 界面，支持搜索、多维度筛选和排序
- 收藏分类系统（自定义分类名称和颜色）
- 作品屏蔽功能
- 图片代理（解决跨域问题）
- 智能限速（默认 10 秒/次，遵守 robots.txt）
- 被限速时自动退避等待
- SQLite 数据库，纯 Go 实现无需 CGO

## 快速开始

```bash
# 编译
go build -o dlsitexz .

# 运行（默认端口 8080）
./dlsitexz

# 自定义端口
PORT=3000 ./dlsitexz

# 自定义数据库路径
DLSITE_DB=/path/to/data.db ./dlsitexz
```

打开浏览器访问 `http://localhost:8080`

## 使用方法

### 单个获取
在「单个获取」页面输入作品 ID（如 `RJ123456`），点击获取即可。

### 批量爬取
在「爬取管理」页面设置 ID 范围（如 RJ01000000 ~ RJ01001000），点击开始。
爬取速度约 6 个/分钟（每次请求间隔 10 秒以避免封禁）。

### 收藏与分类
- 鼠标悬停卡片，点击 ♥ 快速收藏
- 点击卡片查看详情，可选择自定义分类
- 侧边栏底部可创建新分类（自定义颜色）

### 屏蔽
- 鼠标悬停卡片，点击 ✕ 屏蔽该作品
- 侧边栏「已屏蔽」可查看和恢复

## 技术栈

- Go (标准库 + embed)
- SQLite (modernc.org/sqlite, 纯 Go)
- 原生 HTML/CSS/JS (无前端框架)
